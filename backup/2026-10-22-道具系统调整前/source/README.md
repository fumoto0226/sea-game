# Apple Works Demo

运行：`python3 -m http.server 5173`，打开 http://localhost:5173 。无安装依赖。

## 当前范围
- 十级鱼人：兼职鱼人、鱼人社员、网红鱼人、小丑鱼人、国王鱼人、海绵鱼人、变异鱼人、外星鱼人、英雄鱼人、鱼神。
- 对应 Cookie Clicker 前十建筑的基础价格、秒产和 15% 价格递增；×1 / ×10 / ×100 招募。
- 自动贩卖机提供 318 件建筑／点击／带教／全局补给／幸运苹果升级。按价格最多显示 9 件，购买后补货；支持详情、直接购买和道具飞入收藏动画。
- 幸运苹果、60 秒黄金狂热、角色招呼、普通员工进出场；入场最多同时 10 只、间隔 0.7 秒。
- 查看道具、扭蛋机、排行榜和设置仍有占位功能；无离线收益，页面不可见时暂停生产。

## 数值来源与边界

核对 2026-10-19 [Cookie Clicker 官方 main.js](https://orteil.dashnet.org/cookieclicker/main.js)。完整十级对照表、318 件商品构成和待追加机制见 [GAME-PROGRESSION.md](GAME-PROGRESSION.md)。

当前实现前十建筑和对应普通升级，不是完整原作经济系统。成就／牛奶／小猫、研究、糖块小游戏、转生与季节系统尚未实现。用户指定的金苹果基础 60 秒（沙漏升级后 120 秒）和手动点击 ×7 继续保留。

## 备份与存档
旧版完整文件位于 `backup/2026-10-18-原版苹果工厂/`，可直接通过服务器子路径打开。新版存档键为 `apple-works-demo-v1`，与旧版 `sea-farm-demo-v2` 隔离；重置新版不删除旧版存档。

`window.render_game_to_text()` 提供状态；`window.advanceTime(ms)` 用于测试推进时间。

生产按钮音效由本项目使用 Web Audio 即时合成（短促滤波噪声与低频瞬态），未使用 Cookie Clicker 的音频文件。原作声音目录公开可访问，但本次未确认适用于独立项目复用的开放授权。

## 随机苹果

参考原作公开 main.js 的未升级 Golden Cookie：每秒30次判定，等待300–900秒，300秒后每帧出现概率为 `((已等待秒数-300)/600)^5`，通常约7分半；出现后13秒未点消失。计时在出现期间暂停，收取或消失后重新开始。隐藏页面暂停计时，与当前 demo 的生产规则一致。

本版仅包含两种基础结果，改为不同外观的苹果，共用刷新时钟。首次两者各50%；保留原作80%尝试排除上次结果的防重复机制。未包含其他低概率事件，因此整体结果概率并非完整原作概率。

- 幸运苹果：`min(持有苹果 × 15%, 当前实际CPS × 900) + 13`，零CPS时仍获得13。
- 金苹果：自动产量 ×7，按用户要求持续60秒（原作为77秒）；本 demo 按当前设计也将手动点击收益 ×7（这一点与原版基础 Frenzy 不同）。加成期间点击粒子变金，显示金色状态和倒计时。重复领取金苹果刷新至60秒，不叠乘倍率。
- 事件等待、在场苹果和加成剩余时间随存档保留，不计算离线时间。
- 宽屏电脑两侧提供两种刷新测试按钮，手机隐藏。测试按钮只生成待点击苹果，不直接发奖。

资料：[Golden Cookie](https://cookieclicker.wiki.gg/wiki/Golden_cookie)、[原作公开数据](https://orteil.dashnet.org/cookieclicker/main.js)。金苹果图形由本项目提供的苹果 SVG 改色并增加高光，不使用原作美术。

黄金狂热视觉：倒计时仅显示在余额双黑线之间，颜色 #FCF043，数值栏内部保持白色。60秒内切换黄金配色背景、降下装饰金苹果雨，并对总量数字做缩放旋转抖动。雨滴无收益；结束即清除并恢复原场景。

顶部苹果总量使用独立整数格式，保留最多九位整数，达到十位再升单位，例如11,750,000、999,999,999、1,000,000 K；不显示小数。其他价格/产量仍用原有短数字格式。

# v1.0.1 双阶段玩法

## 阶段一：建造工厂

- 从 Lv.1 开始，点击「建造工厂」30次升至 Lv.2，再点击100次升至 Lv.3。免费点击，不增加苹果、不赠鱼人、不赠硬币、不增加点击收益。
- 每轮一个进度条，两个内部刻度；下方空白占位留待以后配置目标图标，目前无目标奖励。
- 固定保留顶部排行榜、工厂名称、设置及版本号；暂不显示苹果余额、秒产、鱼人商店、换装/外出、生产按钮和右上角强化牌。
- Lv.3显示满级确认，可开始经营或查看尚未开放的新工厂入口。未进入经营时不刷新任何随机苹果。

## 阶段二：经营工厂

- 点击「开始经营」后恢复原主页布局。工厂固定Lv.3，右上角为强化工厂与开设新工厂；新工厂入口暂显示未开放。
- 原招募价格从第1只计算：15、100、1100、12000、130000、1400000、20000000、330000000、5100000000、75000000000。没有预留名额或赠鱼导致的价格偏移。
- 卡片直接招募，无鱼人等级/升级箭头。第一种从开始经营即显示，后续沿用累计苹果解锁与两个剪影预览。
- 强化入口恢复原备份中的315件道具，按价格排序，优先显示已解锁且未购买的最便宜项；没有已解锁项时预览最便宜未购买项并显示解锁条件。所有已解锁项均可通过此入口购买，不再分鱼人/扭蛋入口。
- 原机制：142件全体产量、138件单鱼人/基础点击翻倍、8件农民协作、12件全员协作、15件点击按秒产加成。价格、人数、累计产量和手动产量等解锁条件恢复原始定义。没有后来新增的18次点击附加、末三级百分比或100项截断。
- 道具说明沿用黑色主效果、紫色标题和数值、灰色预计收益框。所有类型提供实际数值预估，计算保留精度。
- 原三件随机苹果道具不恢复。基础幸运苹果频率×10、金苹果×4继续生效。两颗独立赠送金苹果分别在经营时间60–120秒、240–300秒随机出现，每轮一次，不影响普通刷新。

## 存档与计时

- 建造阶段也计入本轮在线游戏时间，但经营时间单独记录，从点击开始经营时归零起算。后台/关闭网页不增加这两个时钟。
- 新存档从建造阶段开始；阶段内进度和满级待确认状态可保存/刷新。重新开始清空本轮数据并回到Lv.1。
- v1.0.0存档迁移至建造阶段，保留原有苹果、付费招募、衣橱和能映射到原目录的已购道具；去掉过去免费赠送的鱼人数，清除旧工厂/鱼人福利规则，经营赠送苹果重新计时。原始备份只读。
